# The Rise of Bloody Wolf Version Log

## 模板使用方法：

### Platform
- 直接拖到场景中来创建实例。

组件：
- platform: 在这里为添加模型，并修改位置、旋转、缩放。
- trial: 平台的移动轨迹，平台移动时不会进行roll方向的旋转，始终以样条线切线为方向。调整样条线节点以调整轨迹，右键可创建更多节点。
- box: 开启triggerable后，玩家与此碰撞箱重合触发平台移动。可调节位置和大小。

参数：
- fixed: 是否为晃动平台，暂不开放。
- moveable: 是否为移动平台，开启后会往返移动。
- triggerable: 是否需要触发，开启后只有在玩家碰到碰撞箱时才会往返移动，玩家离开时返回出发点。开启此功能需要将movable设为true。
- speed: 平台速度。

### Enemy
- 直接拖到场景中来创建实例。

组件：
- body: 在这里为添加模型，并修改位置、旋转、缩放。
- bulletStartPoint: 子弹发射位置与方向。注意调整该组件使子弹生成时不会与body组件碰撞，否则看不到子弹射出。会与body一起移动。
- trial: 敌人移动时取节点样条线的为检查点，走直线轨迹，注意不要在路径上放置任何物体。敌人到达最后的节点后会直接消失。调整样条线节点以调整轨迹，右键可创建更多节点。
参数：
- blood: 血量。
- doPatrol: 是否巡逻，开启后会朝检查点移动。
- speed: 移动速度。
- doLoop: 开启后，抵达最后的节点过一段时间后会再次出现在出发点。
- loopInterval: 消失与再出现间的时间间隔。
- doFire: 是否发射子弹。
- bulletInterval: 子弹发射间隔。
- bulletSpeed: 子弹速度。
- bulletDamage: 子弹伤害。


### bullet
- 目前暂不支持多种子弹，仅支持圆形子弹，其他形状的子弹会有方向问题。
- 直接在子弹蓝图中为其设置模型。
